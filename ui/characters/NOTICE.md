# 캐릭터 그림과 대사의 출처

- 출처 : 시사 비서 (https://github.com/cheo0y/shisa-agent), 2026-10-16 받은 판
- 가져온 것 : `assets/character` (시사), `assets/characters/{hachi,rakko,momonga,usagi}` 의 그림과 영상, `assets/characters/lines.json` 과 `agent/src/local-mode.ts` 의 인사, 응원, 할 일 상태 대사
- 파일 이름 : 원본 이름 그대로 둔다 (eyes_open, eyes_closed, dance, cheer, plan, study, studying, video.json). 시사의 반응 그림(`assets/reactions`)은 2026-10-16 박성준 결정으로 쓰지 않아 가져오지 않았다
- `reactions/no_thanks.png` (우는 하치와레, 캐릭터 고르기 창의 「필요 없어」) 는 시사 저장소 것이 아니다. 2026-10-16 박성준이 직접 준 그림이다
- `chiikawa/` (치이카와), `jokebear/` (농담곰) 의 그림도 시사 저장소 것이 아니다. 2026-10-16 박성준이 직접 준 그림이다 (영상 없음)

시사 저장소의 코드는 MIT 라이선스지만, 이 그림과 영상은 치이카와(ちいかわ, © Nagano)의 팬아트라 MIT에 포함되지 않는다. 원 저장소 README는 비상업 용도로만 쓸 수 있고, 고쳐서 배포하거나 상업적으로 쓰려면 직접 만든 그림으로 바꾸라고 적고 있다.

팀원 화면에 띄우는 것은 2026-10-16 박성준이 그 조건을 알고 정했다.
