# 울릭 할 일 — 사용 가이드

할 일을 **중요도 × 급함** 네 칸으로 정리해 두는 팀 공용 도구입니다.
노션에 쌓이고, **브라우저**와 **Claude** 양쪽에서 같은 내용을 봅니다.

---

## 1. 시작하기

### 브라우저로 쓰기 (설정 없음)

**https://todo-widget-web.pangtodo.workers.dev**

1. 접속하면 로그인 화면이 뜹니다 → **회사 메일 주소** 입력
2. 메일로 오는 **6자리 코드**를 입력하면 들어갑니다
3. 끝입니다. 즐겨찾기 해두세요. **폰에서도 됩니다**

한 달에 한 번 정도만 다시 로그인하면 됩니다.

### Claude Code로 쓰기 (한 번만 설정)

따로 받으신 **`본인이름.md`** 파일이 있으실 겁니다.

1. Claude Code를 **아무 폴더에서나** 엽니다
2. 그 파일을 창에 **끌어다 놓습니다**
3. **"이거 보고 세팅해줘"** 라고 말합니다

Claude가 알아서 연결하고 확인까지 해줍니다.

> 이 설정은 **컴퓨터에 저장**됩니다. `/clear` 하거나 세션을 닫아도 사라지지 않고,
> 다른 폴더에서 Claude를 열어도 그대로 붙어 있습니다.
> 컴퓨터를 바꾸면 그 컴퓨터에서 한 번 더 하시면 됩니다.

## 2. `/scmtodo` — 제일 빠른 길

Claude Code에서 `/scmtodo` 뒤에 그냥 말을 붙이면 됩니다.

```
/scmtodo 3PL 견적서 3곳 비교표 내일까지 만들기      넣기
/scmtodo                                        남은 할 일 보기
/scmtodo 위클리 양식 끝냈어                        완료 처리
/scmtodo 창준님 뭐 하고 있어?                      동료 할 일 보기
```

---

## 3. 하루의 시작과 끝

Claude Code에서 **`/`** 를 치고 **`ulick`** 이라고 쳐보세요. 두 개가 뜹니다.

| | 언제 | 하는 일 |
|---|---|---|
| **아침 정리** (`morning`) | 하루 시작할 때 | 남은 일 훑기 → 지난 마감 짚기 → **오늘 끝낼 3개** 고르기 |
| **퇴근 정리** (`evening`) | 하루 끝낼 때 | 오늘 한 일 정리 → 못 끝낸 것 내일로 → **내일 첫 일** 정하기 |

**이 두 개만 습관이 되면 나머지는 저절로 굴러갑니다.** 아침에 한 번, 퇴근 전에 한 번.
각각 1~2분이면 끝납니다.

> 목록에 안 보이면 Claude Code를 껐다 켜보세요.

---

## 4. 평소에는 — 그냥 말하기

명령어를 외울 필요 없습니다. 평소 말하듯 하시면 됩니다.

### 넣기

> **"3PL 견적서 3곳 비교표 내일까지 만들어야 해. 그리고 가영님한테 드랍테스트 일정 물어보기."**

→ 두 건으로 쪼개서, 사분면과 마감일까지 정해서 넣어줍니다.

> **"이번 주에 할 것들 정리해서 넣어줘: 위클리 양식, 재고 실사 체크리스트, 법인카드 정산"**

한꺼번에 던져도 됩니다.

### 보기

> **"오늘 할 일 뭐 남았어?"**
> **"이번 주 마감 뭐 있지?"**
> **"급한 것만 보여줘"**
> **"팀 전체 뭐 있지?"**
> **"창준님 뭐 하고 있어?"**

### 끝내기 / 고치기

> **"위클리 양식 만들기 끝냈어"**
> **"3PL 건은 다음 주로 미뤄줘"**
> **"물류팀 회신 기다리는 중이야"** → `대기중` 으로 표시
> **"오늘은 이 세 개만 하자"** → 오늘 꼭 끝낼 것으로 고정

### 돌아보기

> **"이번 주에 뭐 했지?"**

## 5. 네 칸이 뭔가요

| | **급함** | **안 급함** |
|---|---|---|
| **중요** | **1 지금 당장**<br>오늘 안 하면 터지는 일 | **2 핵심 업무**<br>안 하면 나중에 1번이 되는 일 |
| **안 중요** | **3 빠르게 쳐낼**<br>잡무 | **4 언젠가**<br>지금은 아닌데 버리긴 아까운 것 |

**요령은 2번 칸입니다.** 아무도 재촉하지 않아서 계속 밀리는데,
여기를 비워두면 하루가 잡무(1번·3번)로만 끝납니다. 하루 한 칸씩만 처리해도 달라집니다.

어디 넣을지 헷갈리면 Claude에게 그냥 던지세요. 알아서 정하고, 애매하면 물어봅니다.

## 6. 화면에서 할 수 있는 것

- **동그라미 클릭** — 완료 처리 (완료일이 자동으로 기록됩니다)
- **★** — 오늘 꼭 끝낼 것으로 위에 고정 (최대 3개)
- **끌어서 옮기기** — 항목 순서, 칸 위치 바꾸기
- **메모** — 각 항목에 비고 달기. "결과물: OO 1장" 처럼 적어두면 나중에 편합니다
- **담당자 줄** — 이름을 누르면 그 사람 할 일이 보입니다
- **탭** — `매트릭스`(네 칸) / `날짜` / `캘린더`(마감일 달력) / `기록`
- **캘린더** — 마감일이 달력에 얹혀 나옵니다. 막대 색이 네 칸 번호고, 마감이 지난
  것은 빨갛습니다. 날짜를 누르면 그 날 마감인 일만 아래에 펼쳐집니다

---

## 7. 알아두실 것

- **서로의 할 일이 보입니다.** 팀에서 열어두기로 한 부분입니다.
  누가 뭘 하고 있는지 알면 중복도 줄고 물어볼 일도 줍니다
- **고치고 완료 처리하는 건 본인 것만 됩니다.** 실수로 남의 할 일을 지우는 일을 막으려는 것입니다.
  남의 항목을 손대야 하면 그분께 말씀하세요
- **팀장은 전체를 봅니다.** 업무 현황 파악용입니다
- 브라우저에서 하든 Claude에서 하든 **같은 데이터**입니다. 한쪽에서 고치면 양쪽 다 바뀝니다
- **작업하다 미룬 일이 생기면 Claude가 먼저 물어봅니다.**
  *"Ulick To-do에 넣어둘까요? — 창준님께 스캐너 통관 일정 확인받기"* 처럼 한 줄로요.
  필요 없으면 아니라고 하시면 되고, 그 세션에서는 다시 안 묻습니다

## 8. 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 다시 로그인하라고 나옴 | 정상입니다. 한 달에 한 번 정도 코드를 다시 받습니다 |
| 코드 메일이 안 옴 | 스팸함 확인. 그래도 없으면 팀장에게 말씀해주세요 |
| "등록되지 않은 사용자" | 계정 등록이 안 된 것입니다. 팀장에게 말씀해주세요 |
| Claude가 할 일 도구를 못 찾음 | `claude mcp list` 로 `ulick-todo` 가 있는지 확인. 없으면 받으신 md로 다시 세팅 |
| 슬래시 명령이 `/` 목록에 없음 | Claude Code를 껐다 켜보세요 |
| `/scmtodo` 가 없음 | 받으신 md를 Claude에 다시 주고 "설정 마저 해줘" 하시면 됩니다 |
| 그 외 이상한 것 | 화면 캡처해서 팀장에게 보내주세요 |

## 9. 처음 이틀은 이렇게

1. **아침에 한 번** — `/` → `ulick` → **아침 정리**
2. **생각날 때마다** — `/scmtodo 할 일 내용` 으로 바로 던져 넣기. 정리는 Claude가 합니다
3. **끝낼 때마다** — "OO 끝냈어" 로 지우기
4. **퇴근 전에 한 번** — `/` → `ulick` → **퇴근 정리**

며칠 해보시고 불편한 점 있으면 알려주세요. 고칠 수 있습니다.
