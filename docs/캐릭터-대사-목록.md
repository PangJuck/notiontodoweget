# 캐릭터 대사 목록

원본 : `ui/characters/lines.json`. 고치려면 그 파일을 고친다. 빈 칸은 그 캐릭터에 없어서 응원 중 하나가 무작위로 나온다.
`{total}` 오늘의 3 개수, `{done}` 끝낸 개수, `{left}` 남은 개수, `{rest}` `{next}` 남은 일 제목, `{title}` 할 일 제목, `{titles}` 끝낸 일 제목들

## 시사 (`shisa`)

- 아침 인사 (5~12시) : 좋은 아침이에요.
- 점심 인사 (12시) : 점심 시간이에요.
- 오후 인사 (13~18시) : 좋은 오후예요.
- 저녁 인사 (18시 뒤) : 좋은 저녁이에요.
- 오늘의 3 중 일부 끝냈을 때 : 오늘 할 일 {total}개 중 {done}개 끝냈어요. 남은 건 {rest}예요.
- 오늘의 3 하나도 못 했을 때 : 오늘 할 일 {total}개 중 아직 끝낸 건 없어요. 하나만 먼저 해 봐요.
- 오늘의 3 다 끝냈을 때 : 오늘 할 일 {total}개 다 끝냈어요! 정말 잘하셨어요.
- 오늘의 3 이 비어 있을 때 : 오늘 할 일이 아직 비어 있어요.
- 오늘의 3 을 고르라고 할 때 : 오늘 할 일로 고른 건 아직 없어요. 할 일 {n}개가 기다리고 있어요.
- 가장 급한 할 일 알려 줄 때 : 지금은 '{title}'부터 해 보면 좋겠어요.
- 할 일 일깨울 때 : 오늘 꼭 할 일을 다시 일깨워 드려요.
- 끝낸 일 칭찬할 때 : 최근에 {titles}을 끝내셨어요. 잘하셨어요.
- 응원 (누를 때, 할 일 끝낼 때, 20분마다 하나씩 무작위)
  - 오늘도 잘하고 있어요. 제가 옆에서 응원할게요!
  - 천천히 해도 괜찮아요. 하나씩 하면 다 돼요.
  - 벌써 여기까지 왔어요. 조금만 더 힘내요!
  - 잠깐 숨 고르고 물 한 잔 마셔요. 그다음에 같이 해 봐요.
  - 오늘 한 일도 충분히 대단해요. 수고 많으셨어요.
