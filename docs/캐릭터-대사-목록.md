# 캐릭터 대사 목록

원본 : `ui/characters/lines.json`. 고치려면 그 파일을 고치고 `python scripts/lines_doc.py` 로 이 문서를 다시 뽑는다. 빈 칸은 그 캐릭터에 없어서 응원 중 하나가 무작위로 나온다. 여러 줄이면 그중 하나가 무작위로 나온다.
`{total}` 오늘의 3 개수, `{done}` 끝낸 개수, `{left}` 남은 개수, `{rest}` 남은 일 제목, `{n}` 할 일 개수, `{title}` 할 일 제목, `{titles}` 끝낸 일 제목들
