# 아이콘

| 파일 | 쓰이는 곳 |
|---|---|
| `app.png` | 48~256px. 바탕화면 아이콘, 큰 아이콘 보기 |
| `app.small.png` | 16~32px. 시스템 트레이, 작업표시줄 |
| `app.ico` | 위 둘을 구워낸 결과물. `make_icon.py`가 만든다 (git에 안 올린다) |

## 왜 두 장인가

윈도우 트레이는 16px다. 그 크기에 전체 장면을 밀어 넣으면 무슨 그림인지 알아볼 수 없다.
그래서 작은 크기에는 주인공만 크게 잘라둔 `app.small.png`를 쓴다.
`.ico` 한 파일 안에 크기별로 다른 그림을 담을 수 있어서 가능한 일이다.

`app.small.png`는 선택이다. 없으면 모든 크기에 `app.png`를 쓴다.
둘 다 없으면 4사분면 모양을 그려서 쓴다. 파이썬 기본 깃털 아이콘은 어떤 경우에도 안 뜬다.

## 갈아끼울 때

`app.png`(와 원하면 `app.small.png`)만 덮어쓰면 된다. `.ico`는 빌드가 다시 굽는다.

- 정사각형이 아니어도 된다. 비율을 유지한 채 투명 여백을 채워 정사각형으로 맞춘다
- 배경이 투명한 PNG여야 한다. 배경색이 박혀 있으면 작업표시줄에 색 네모로 뜬다
- 256px 이상을 권한다. 그보다 작으면 큰 아이콘 보기에서 흐려진다
