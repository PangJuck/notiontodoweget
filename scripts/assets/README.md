# 아이콘

`app.png` 하나만 넣으면 된다. 나머지는 빌드가 알아서 한다.

- 정사각형이 아니어도 된다. `make_icon.py`가 비율을 유지한 채 투명 여백을 채워 정사각형으로 맞춘다
- 배경이 투명한 PNG가 제일 깔끔하다
- 512×512 이상을 권한다. 작은 그림을 키우면 작업표시줄에서 뭉갠다

`app.ico`는 `make_icon.py`가 `app.png`에서 구워낸 결과물이라 직접 만들 필요가 없다.
`app.png`가 없으면 4사분면 모양을 임시로 그려서 쓴다. 파이썬 기본 깃털 아이콘은 뜨지 않는다.

쓰이는 곳 세 군데:

| 자리 | 가져다 쓰는 파일 |
|---|---|
| exe 파일 아이콘, 작업표시줄 | `app.ico` |
| 시스템 트레이 아이콘 | `app.png` |
| 창 제목표시줄 | `app.ico` |
